# Bora Memória

**Organized knowledge. Continuity for your projects.**

[Português](README.md) · [Download for Windows](https://github.com/boracriarcomia/bora-memoria/releases/latest) · [Documentation](docs/README.md) · [Community](https://boracriarcomia.com.br)

Bora Memória is a free desktop application for keeping notes, references, decisions and tasks in a local vault. Its knowledge graph helps you navigate connections, while a local MCP bridge lets compatible AI clients read context and track authorized work.

## Features

- Markdown notes, images and attachments in real folders.
- An interactive graph of connected information.
- Tasks with priorities, owners, evidence and change history.
- Centralized project decisions, brand guidelines and work standards.
- Local MCP integration with execution leases and attributable operations when identity is supplied.
- Complete local backups and optional Google Drive uploads.

## Get started on Windows

1. [Download the installer from the latest release](https://github.com/boracriarcomia/bora-memoria/releases/latest).
2. Run it and choose the application folder.
3. Open Bora Memória and create or select your vault.

Requires 64-bit Windows 10/11 and Microsoft Edge WebView2. Python is not required to use the packaged application. The installer is unsigned; Windows may display an unknown publisher warning.

See the [installation and recovery guide](docs/INSTALLATION.en.md) before upgrading or moving your data.

## Your data stays under your control

Notes and attachments live in your selected vault. SQLite stores tasks and history; JSON stores settings and current context. Personal vaults, backups and credentials are not included in the repository or installer.

Google Drive is optional and requires your own configuration and authorization. Automatic uploads run while the app is open or in the notification area. Backups are versioned copies, not bidirectional folder synchronization.

## AI with project context

The MCP bridge runs independently of the desktop window. Compatible clients can consult guidelines, claim tasks and record authorized work. Bora does not include an AI model; availability and costs depend on your chosen client.

Agent names are declared by the lease holder. The ledger supports accountability but does not authenticate the provider or guarantee error-free AI behavior. See the [AI integration guide](docs/INTEGRACAO-IA.md) and [workflow criteria](docs/FLUXO-E-CRITERIOS.md), currently in Portuguese.
