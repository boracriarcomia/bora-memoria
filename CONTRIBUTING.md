# Contribuir com o Bora Memória

[English](CONTRIBUTING.en.md)

Queremos ajudar pessoas a organizar projetos, informações e continuidade de trabalho com IA, mantendo seus arquivos sob seu controle.

Para sugerir melhorias ou relatar falhas, abra uma issue. Explique o objetivo, passos para reproduzir, resultado esperado e versão do aplicativo. Não publique seu cofre, senhas, tokens ou dados de clientes.

Para propor código, faça um fork, crie uma branch e envie um pull request com uma mudança objetiva, explicação e validação. Execute `python -m unittest discover -p "test_*.py"` antes de enviar. Mudanças de comportamento precisam de testes pertinentes; ajustes de texto não exigem testes artificiais.

Pull requests são propostas. A equipe Bora revisa e decide se incorpora a mudança no projeto oficial. Sugestões também podem ser discutidas em português ou inglês. A licença MIT permite manter e distribuir seu próprio fork.

Para vulnerabilidades, consulte [SECURITY.md](SECURITY.md) e evite expor detalhes de exploração em issues públicas.
