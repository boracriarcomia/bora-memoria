# Instalação e recuperação

## Instalar no Windows

1. Baixe o instalador em [Releases](https://github.com/boracriarcomia/bora-memoria/releases/latest).
2. Escolha a pasta do programa e conclua a instalação.
3. Abra o aplicativo pelo atalho. Crie seu cofre ou selecione uma base existente.

Requisitos: Windows 10/11 de 64 bits e Microsoft Edge WebView2. Python não é necessário para usar o executável. O pacote não tem assinatura digital.

## Atualizar

Salve os rascunhos, exporte o cofre completo e escolha **Sair** no ícone da bandeja antes da atualização. Fechar a janela pode apenas ocultar o aplicativo. Preserve a pasta do cofre e confirme a base selecionada ao reabrir.

## Backup e recuperação

O backup completo contém notas, anexos e dados de acompanhamento. Para recuperar, extraia o ZIP em outra pasta e abra o cofre recuperado. Confira o conteúdo antes de substituir qualquer base existente. O backup menor de notas não inclui todos os anexos.

O Google Drive é opcional e exige autorização individual. Seus backups são versionados; o recurso não faz sincronização bidirecional entre pastas. A execução automática depende do aplicativo aberto ou na bandeja.
