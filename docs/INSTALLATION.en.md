# Installation and recovery

## Install on Windows

1. Download the installer from [Releases](https://github.com/boracriarcomia/bora-memoria/releases/latest).
2. Choose an installation directory and finish setup.
3. Open the application and create a vault or select an existing one.

Requirements: 64-bit Windows 10/11 and Microsoft Edge WebView2. Python is not required to run the executable. The distribution is unsigned.

## Update safely

Save drafts, export a complete vault backup and choose **Exit** from the notification area before updating. Closing the window may only hide the application. Preserve your vault directory and check the selected vault after reopening.

## Recover a backup

Extract the complete ZIP into a separate directory, then open its recovered vault. Check the contents before replacing an existing vault. The smaller notes backup does not include all attachments.

Google Drive is optional and requires individual authorization. Backups are versioned, not bidirectional folder synchronization. Automatic backup requires the application to be running or in the notification area.
