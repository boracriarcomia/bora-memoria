# Segurança / Security

Relate possíveis vulnerabilidades de forma privada para contato@boracriarcomia.com.br. Informe a versão e uma descrição suficiente para reproduzir em uma base fictícia. Não envie credenciais, dados pessoais ou seu cofre real. Não há prazo de resposta garantido ou programa de recompensa anunciado.

Report suspected vulnerabilities privately to contato@boracriarcomia.com.br. Include the version and reproduction details using synthetic data. Do not send credentials, personal data or a real vault. No guaranteed response time or paid bounty program is offered.

O aplicativo guarda dados localmente. A pasta escolhida precisa de permissões adequadas, e o usuário deve manter backups fora do computador. Não use duas instâncias para editar o mesmo cofre simultaneamente.

The app stores data locally. Protect the selected folder with appropriate permissions and keep backups outside the computer. Do not edit the same vault concurrently from multiple instances.
