# Contributing to Bora Memória

[Português](CONTRIBUTING.md)

Our goal is to help people organize projects, knowledge and AI-assisted work while keeping ownership of their local files.

Open an issue to propose an improvement or report a bug. Include the goal, reproduction steps, expected behavior and application version. Never upload personal vaults, credentials, tokens or customer data.

To contribute code, fork the repository, create a branch and submit a focused pull request describing the change and validation. Run `python -m unittest discover -p "test_*.py"`. Add meaningful tests for behavior changes; documentation-only changes do not need artificial tests.

Pull requests are proposals. Bora maintainers review and decide what becomes part of the official project. Discussions can be in Portuguese or English. The MIT license also allows you to maintain and distribute your own fork.

For vulnerabilities, use [SECURITY.md](SECURITY.md) rather than disclosing exploit details in public issues.

Contact: contato@boracriarcomia.com.br. Community: https://boracriarcomia.com.br.
